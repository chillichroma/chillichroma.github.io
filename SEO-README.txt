-------------------------------------------
인증 태그 적용 완료.
1) GitHub 배포 후 Search Console에서 소유권 확인
2) 사이트맵 메뉴에서 sitemap.xml 제출

3. 네이버 서치어드바이저 — 네이버 유입검색어
------------------------------------------------
인증 태그 적용 완료.
1) GitHub 배포 후 서치어드바이저에서 소유확인

네이버 검색 노출·클릭·검색어는 서치어드바이저 리포트에서 확인합니다.
